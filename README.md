## FRTMProxy

**A fast, native macOS app to inspect, mock, and reshape HTTP/S traffic in real time.**

Free, public domain, and built with SwiftUI on top of mitmproxy. It includes breakpoints, Map Local,
record and replay, scripting, WebSocket inspection, traffic shaping, and guided device setup.
